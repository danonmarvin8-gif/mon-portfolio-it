Projet Infrastructure SISR · 2025

Lab Réseau Windows Server Automatisé

Déploiement complet d'une infrastructure d'entreprise virtualisée (3 serveurs) avec scripts d'automatisation PowerShell.

Architecture Réseau (3 Nœuds)

🖥️

SRV-A · Contrôleur Primaire

IP : 192.168.10.10 /24

Active Directory Domain Services (AD DS), DNS Primaire, Zone intégrée AD, GPO de sécurité des postes.

🌐

SRV-B · Routeur & DHCP

IP : 192.168.10.1 (LAN) / NAT (WAN)

Routage et Accès Distant (RRAS), NAT pour accès Internet des VM, Étendue DHCP avec basculement 80/20.

🖧

SRV-C · DC Secondaire & Fichiers

IP : 192.168.10.20 /24

Contrôleur de domaine répliqué, DHCP Failover (mode équilibrage de charge), Partage DFS et droits NTFS.

Extrait du Script d'Automatisation PowerShell (srv-b-router.ps1)

# Automatisation de l'installation et configuration du routage NAT Write-Host "[+] Installation du rôle Accès à distance..." -ForegroundColor Cyan Install-WindowsFeature -Name Routing -IncludeManagementTools Write-Host "[+] Configuration du service de routage..." -ForegroundColor Cyan Install-RemoteAccess -VpnType RoutingOnly Write-Host "[+] Activation du routage NAT sur l'interface WAN..." -ForegroundColor Cyan netsh routing ip nat add interface "Ethernet-WAN" full netsh routing ip nat add interface "Ethernet-LAN" private Write-Host "[+] Configuration de l'étendue DHCP avec basculement..." -ForegroundColor Cyan Add-DhcpServerv4Scope -Name "Scope-Entreprise" -StartRange 192.168.10.50 -EndRange 192.168.10.200 -SubnetMask 255.255.255.0 Set-DhcpServerv4OptionValue -DnsServer 192.168.10.10 -Router 192.168.10.1 Add-DhcpServerv4Failover -Name "DHCP-Failover-Pair" -PartnerServer 192.168.10.20 -ScopeId 192.168.10.0 -Mode LoadBalance
