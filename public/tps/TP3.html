Métier

🕵️ Pentester

Testeur d'intrusion / Ethical Hacker

Description

Le pentester (ou testeur d'intrusion) simule des attaques informatiques sur les systèmes d'une organisation pour en identifier les failles avant que des hackers malveillants ne le fassent. Il rédige ensuite des rapports détaillés avec des recommandations de correction.

Compétences requises

Kali LinuxMetasploitPythonRéseaux TCP/IPOWASPScripting

Salaire indicatif

Débutant : 35 000 – 45 000 €/an · Senior : 55 000 – 80 000 €/an

Métier

🔒 DevSecOps

Développeur Sécurité Opérations

Description

Le DevSecOps intègre les pratiques de sécurité à toutes les étapes du développement logiciel (CI/CD). Il automatise les tests de sécurité, analyse les vulnérabilités du code et supervise les déploiements en production de manière sécurisée.

Compétences requises

DockerKubernetesGit CI/CDSAST/DASTTerraformLinux

Salaire indicatif

Débutant : 38 000 – 48 000 €/an · Senior : 60 000 – 90 000 €/an

Métier

💻 Développeur Web

Création d'applications et sites web

Description

Le développeur web conçoit et code des sites web et applications web. Il travaille sur le front-end (interface visible) et/ou le back-end (serveur, base de données, API). Il collabore avec les designers et les chefs de projet pour livrer des produits fonctionnels et performants.

Compétences requises

HTML/CSSJavaScriptReact / VuePHP / Node.jsSQLGit

Salaire indicatif

Débutant : 28 000 – 38 000 €/an · Senior : 50 000 – 70 000 €/an

Métier

🌐 Admin Réseau

Administrateur Systèmes & Réseaux

Description

L'administrateur réseau gère et maintient l'infrastructure informatique d'une entreprise : routeurs, commutateurs, pare-feux, VLANs, VPNs. Il assure la disponibilité, la performance et la sécurité du réseau. Il intervient en cas de panne et planifie les évolutions.

Compétences requises

Cisco IOSVLANVPNActive DirectoryPowerShellWireshark

Salaire indicatif

Débutant : 28 000 – 36 000 €/an · Senior : 45 000 – 65 000 €/an

Métier

☁️ Ingénieur Cloud

Infrastructure Cloud & Virtualisation

Description

L'ingénieur cloud conçoit et gère des infrastructures hébergées sur des plateformes cloud (AWS, Azure, GCP). Il met en place la scalabilité automatique, la haute disponibilité et optimise les coûts. Il travaille avec des outils d'Infrastructure-as-Code pour automatiser les déploiements.

Compétences requises

AWS / AzureTerraformDockerKubernetesPythonLinux

Salaire indicatif

Débutant : 40 000 – 50 000 €/an · Senior : 65 000 – 95 000 €/an
